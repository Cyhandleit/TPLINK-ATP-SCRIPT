📷 Screenshot Red Box Highlight Selector case_highlights

Key is case ID, value is CSS selector list to draw red box on final pass screenshot. Example: {'1.1': ['#login-btn', 'text=Basic']}, selector related to router model (Omada / traditional SMB UI), silently skipped if no match.

After modification, click "Save Config" at top to persist; takes effect when subsequent cases pass after saving.
